DOCX → HWPX 변환기

파일 형식은 .html입니다. 일반 브라우저에서 실행할 때는 보안상 한글 프로그램을 직접 호출할 수 없으며, Windows의 mshta.exe로 실행하면 설치된 한컴오피스 한/글의 변환 엔진을 사용합니다.
준비 중…
HTML 파일 실행 방법

1. 이 파일을 GitHub에 그대로 업로드할 수 있습니다.
2. 사용자는 .html 파일을 다운로드합니다.
3. Windows에서 Win + R을 누르고 아래 형식으로 실행합니다.
mshta.exe "C:\경로\DOCX_to_HWPX_변환기.html"

일반 Chrome/Edge에서 직접 실행하는 경우에는 한글 COM 접근이 차단되므로 실제 변환은 수행되지 않습니다.
